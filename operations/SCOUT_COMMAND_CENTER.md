# Scout Command Center

Scout's offline HTML dashboard is generated by `python operations/scout_dashboard.py` after website qualification and contact discovery. Each scheduled or manual GitHub Actions run includes `scout_command_center.html` in the **scout-autodrafts-review** artifact. Download and open it locally on an iPhone or computer. No hosting, login, payment, or live network connection is required.

**Queues**
- Drafts needing attention: automatically shown only when a public same-domain contact email and a fetched website observation exist.
- Replies needing attention: optional `operations/replies.csv` with columns `business,from,subject,next_action,status`. Include only real replies; set status `needs_attention`, `unread`, or `awaiting_reply`.
- Active clients: optional `operations/clients.csv` with columns `business,service,next_action,status`. Status `active` or `in_progress`.
- Work needing attention: optional `operations/client_tasks.csv` with columns `business,task,notes,status`. Set `done` to remove from the open queue.

The three optional CSVs are **not** generated from Gmail or invented. No mailbox is connected to this dashboard. Do not commit private correspondence or client information to a public repository; keep such CSVs local/private. To import private records, generate the HTML locally rather than committing them.

**Safety and limits**: Review-only; no messages sent. HTTP/HTML findings are preliminary, not confirmed vulnerabilities or proof of a business problem. Passive public-page review does not constitute a penetration test. Scout's agent is **John Laering, Virtual Client Relations Agent, Cairnflow Private**.
